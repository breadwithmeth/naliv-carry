Показ доставленных заказов через GET /courier/orders/delivered

Контекст: API (`getDeliveredOrders` в `src/api/ordersApi.ts:174`, формат `YYYY-MM-DD`) и стор (`fetchDeliveredOrders`, `deliveredOrders`, `deliveredStats` в `src/store/ordersStore.ts:159`) уже существуют, но UI их не использует. Сейчас фильтр «Выданы» в OrdersPage работает только клиентски по my-deliveries.

Изменения (только `src/pages/OrdersPage.tsx`):

1. При выборе фильтра «Выданы» (`done`) вызывать `fetchDeliveredOrders(startDate, endDate)` с фиксированным периодом: первый день текущего месяца → сегодня (даты в формате `YYYY-MM-DD`, локальное время).
2. Список для фильтра `done` брать из `state.deliveredOrders` вместо клиентской фильтрации `myOrders` по статусу. Поиск (имя/адрес/телефон/ID) по-прежнему применяется поверх.
3. Fallback: если запрос упал (офлайн) — использовать прежнюю клиентскую фильтрацию по `myOrders` со статусом `delivered`, чтобы список не был пустым без причины.
4. Показать над списком статистику из `deliveredStats` (количество доставленных + суммарный заработок) в стиле существующей верстки (простая строка/блок).
5. Сброс фильтра и остальные вкладки («Активные», «Все», «Проблемы») работают как раньше по `myOrders`.
6. Период фиксированный, кэшируется на время сессии: повторный выбор «Выданы» перезапрашивает данные (свежесть важнее экономии запроса).

Проверка: `npm run build` / typecheck, вручную — переключение вкладки «Выданы» грузит данные с сервера.
